Terminal Navigation

Terminal Linux ka dil hai. Filesystem mein move karna — yeh foundation hai jis pe baaki sab build hoti hai.

Linux filesystem ek tree hai. Root / se shuru hoti hai. Teri files /home/username/ mein hain. System config /etc/ mein. Logs /var/log/ mein. Programs /usr/bin/ mein. Terminal is tree ka navigator hai.
📁
Absolute Path
Root se shuru: /home/hadi/projects/ — hamesha same path chahe tum kahan bhi ho terminal mein.
📂
Relative Path
../documents/ — current location se relative. Double dot (..) ek level upar. Zyada fast hai typing ke liye.
🏠
Home Directory (~)
~ matlab /home/username/. cd ~ ya sirf cd — hamesha ghar wapas. Shortcut hai sab jagah.
📍
Working Directory
Abhi tum kahan ho terminal mein. pwd se check karo. Relative paths is location se count hoti hain.
pwdPrint Working Directory — Abhi kahan ho?
▼
Kya Hai
pwd (Print Working Directory) tera current location print karta hai. Jab bhi confused ho ke "main kahan hun filesystem mein" — yeh chalao. Scripts mein directory track karne ke liye bhi use hota hai.
Syntax & Flags
pwd # current directory print karo /home/hadi pwd -L # logical path (symlinks follow) — default behaviour pwd -P # physical path (real location, no symlinks)
Real Use Cases
Script mein current dir save karo
STARTDIR=$(pwd) && cd /tmp && do_work && cd "$STARTDIR"
Script mein alag dirs pe kaam karo aur wapas aao same jagah pe
rm se pehle ZAROOR check karo
pwd # confirm karo ke sahi jagah pe ho — ghalat delete na ho!
Production server pe yeh life-saving habit hai — hamesha pehle pwd
Bash prompt mein current dir dikhao
export PS1="\$(pwd) \$ " # .bashrc mein add karo
Hamesha pata rahega kahan ho — confuse nahi hoge

-a--allHidden files bhi (.dotfiles)
-h--human-readableSize KB/MB mein (bytes nahi)

Important System Directories — Zarur Yaad Karo
/ — Root. Poora filesystem yahan se shuru hota hai.
/home/username/ — Teri personal files. Django projects, downloads yahan.
/etc/ — System config files. nginx.conf, sshd_config, hosts, fstab yahan.
/var/log/ — Sab logs. nginx errors, auth logs, syslog yahan hote hain.
/var/www/ — Web files. Nginx ka default web root.
/usr/bin/ — User programs. python3, git, nginx executables yahan.
/usr/local/bin/ — Manually installed programs yahan aate hain.
/tmp/ — Temporary. Reboot pe delete ho jaate hain.
/proc/ — Virtual FS. Running processes. cat /proc/cpuinfo = CPU info.
/dev/ — Devices. /dev/sda = hard drive. /dev/null = output discard.
/opt/ — Optional 3rd-party software.
/run/ — Runtime files. Sockets, PIDs. /run/nginx.pid etc.

chmodChange Mode — Permissions badlo
▼
Do Tarike — Numeric aur Symbolic
── Numeric Mode (Recommended) ───────────── chmod 755 script.sh # rwxr-xr-x — executable script chmod 644 config.py # rw-r--r-- — regular file chmod 600 ~/.ssh/id_rsa # SSH private key — MUST BE 600 chmod 400 .env # read-only .env — production chmod -R 755 static/ # recursive — dir ke andar bhi chmod -R 644 media/ # media files permissions ── Symbolic Mode (Readable) ──────────────── chmod u+x script.sh # user ko execute do chmod g-w file.txt # group se write permission hato chmod o=r file.txt # others = sirf read chmod a+x script.sh # all ko execute do chmod ug=rw,o=r file # complex combo ek saath # u=owner g=group o=others a=all | +=add -=remove ==set
Real Use Cases
Django — nginx ke liye static files
sudo chmod -R 755 /var/www/myapp/staticfiles/
Nginx www-data user static files read aur traverse kar sake
SSH key secure karna — MUST DO
chmod 700 ~/.ssh && chmod 600 ~/.ssh/id_rsa && chmod 644 ~/.ssh/id_rsa.pub
Private key 600 nahi to SSH connection refuse kar deta hai
Script executable banana
chmod +x deploy.sh && ./deploy.sh
Script likhne ke baad execute permission do phir chalao

Boot Process & System Internals

Linux kaise start hota hai — BIOS se lekar login prompt tak. Yeh samajhna troubleshooting ke liye critical hai.

Boot sequence yaad karo: Power On → BIOS/UEFI → GRUB → Kernel → initramfs → systemd → Login. Har step pe kuch fail ho sakta hai — isliye yeh samajhna zaroori hai.
🔌
BIOS (Legacy)
Basic Input/Output System. Old firmware. MBR (Master Boot Record) se boot karta hai. 2TB disk limit. Ab rare hai.
⚡
UEFI (Modern)
Unified Extensible Firmware Interface. Fast boot, secure boot, GPT support, 9ZB disk limit. 2012 ke baad sab systems.
🥾
GRUB2
GRand Unified Bootloader. Multiple OS boot karne deta hai. Kernel ko RAM mein load karta hai. Ubuntu ka default.
🐧
systemd
PID 1 — pehla process. Baaki sab processes ka parent. Services parallel start karta hai. Fast boot ka raaz yahi hai.

▼
Complete Boot Flow
